## Escopo e componentes

O recorte não inclui pacotes de skills de terceiros. O runtime usa a biblioteca padrão, mas não distribui Python ou dependências externas dentro do wheel. Python, o sistema operacional, Git quando aplicável e ferramentas opcionais de obtenção de skills continuam componentes externos; este documento não altera os termos de seus titulares. Consulte os requisitos na [instalação](docs/installation.md).
