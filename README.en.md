# Zuuuin Skills

Prepared version **0.1.1** contains eight engine skills and the separate Python runtime **0.1.1**, with **zero domain skills**. Own content is licensed under [MIT](LICENSE), with **enayzuin** as the named public author and copyright holder. The selected repository is [enayzuin/zuuuin-skills](https://github.com/enayzuin/zuuuin-skills), and the documentation target is [GitHub Pages](https://enayzuin.github.io/zuuuin-skills/). These are planned destinations; this local copy does not establish publication, availability or approval to expose the exact package.

The skill instructions remain in Portuguese. Start with the [Portuguese overview and eight-skill table](README.md), then follow [installation](docs/installation.md), [usage](docs/usage.md) and the [synthetic examples](examples/README.md). Once tag `v0.1.1` is published, obtain the [tagged source archive](https://github.com/enayzuin/zuuuin-skills/archive/refs/tags/v0.1.1.tar.gz) or visit the [release page](https://github.com/enayzuin/zuuuin-skills/releases/tag/v0.1.1), extract into a new directory and follow the local verification steps. No current tag or downloadable asset is asserted here.

The runtime needs Python >=3.10 and POSIX `fcntl`/`O_NOFOLLOW`. The observed environment was macOS with Python 3.14.8. Optional consumer CLI `skills@1.7.4` requires Node >=22.20; Node 24.19.0 was observed. Manual project copying does not need Node. Install the supplied wheel offline into a separate virtual environment, then create a **new private profile outside this delivery** with `tools/init_profile.py`.

Local synthetic observations do not establish production efficacy, aggregate comparative gain or autonomous client activation. Installation does not guarantee reload or use in the next message. Keep requests, outputs and private state in your own profile. No external account, Obsidian or Linear connection is required by the initial profile.
