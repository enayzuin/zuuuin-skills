Módulos compartilhados de apoio

Estes módulos pertencem ao modelo selecionado e não recebem grupo vazio de skills. Apoiá-los conceitualmente não demonstra uma implementação independente nem cobertura operacional.

  • **Contexto e continuidade**: Recuperar fontes e estado retomável sem depender da narrativa de um chat.
  • **Evidência e limites de atuação**: Proveniência, autorização e recibos de efeitos observados.

Formatos de descoberta

llms.txt é uma entrada Markdown com links relativos. A proposta v2 orienta o formato; não garante descoberta, instalação ou ativação por todo consumidor. Resolução HTTP e comportamento no destino ainda dependem de verificação própria.

skills.sh.json agrupa os oito nomes em três módulos primários não vazios. O arquivo segue o schema oficial no formato gerado. Segundo a documentação de personalização, esse agrupamento trata da apresentação de uma página de repositório; não altera a instalação pelo CLI. Sua presença local não comprova listagem ou consumo pelo serviço.

As páginas Markdown por skill já fazem parte da entrega. O índice apenas as referencia. Para conferir os três arquivos gerados, execute `python3 -I -B tools/build_discovery.py --check` a partir da raiz da entrega. O gerador usa somente os dois catálogos públicos como dados e não faz chamadas de rede.
