Exemplos sintéticos

Todos os dados destas entradas são demonstrativos. Nenhuma entrada identifica um projeto real ou concede permissão para consultar uma conta.

`project-map.request.json` descreve uma fonte completa com um requisito e seu aceite. `router.request.json` descreve uma conversa fora do escopo. As respostas são gravadas apenas no perfil privado escolhido.

Os arquivos `*.expected.json` são fragmentos estáveis da saída esperada: compare esses campos, preservando também os campos adicionais da resposta real. IDs e horários são gerados a cada execução; não se espera igualdade integral do JSON. Um requisito com prioridade/frequência desconhecida continua com esses campos null, sem métricas inventadas.

Depois de preparar o runtime e o perfil conforme instalação, execute os exemplos conforme uso. Não grave os resultados dentro desta distribuição.

Conteúdo próprio de enayzuin sob MIT. Prévia local com indexação desabilitada. Nenhum envio ou hospedagem foi executado por este gerador.
